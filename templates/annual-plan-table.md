# 模板：年度金融教育工作计划表（表格版 / Excel）

> 交付文件名：`{年份}年度金融教育工作计划表.xlsx`
> **必须与文字版 `templates/annual-plan.md` 同时交付**。
> 本文件定义工作表结构、列与校验规则；生成 xlsx 时按此建表。

## 工作表 1：`年度活动清单`

| 列名 | 类型 | 填写规则 |
|------|------|----------|
| 序号 | 整数 | 连续编号 |
| 活动/任务名称 | 文本 | 与文字版"重点任务"章节对应 |
| 类型 | 枚举 | 集中式活动 / 日常普及 / 阵地建设 / 内容创作 / 内部培训 / 评估改进 |
| 目标人群 | 文本 | 与文字版"重点人群"一致，可多选分号分隔 |
| 渠道/形式 | 文本 | 网点、社区、校园、公众号、短视频、广播、短信等 |
| 活动场次 | 整数 | 该项计划场次 |
| 预计覆盖人次 | 整数 | 注明线上线下去重口径（在备注列） |
| 原创作品数 | 整数 | 内容创作类必填 |
| 开始时间 | 日期 | 与监管时间节点对齐 |
| 结束时间 | 日期 | — |
| 牵头部门 | 文本 | 不得写"相关部门" |
| 配合部门 | 文本 | — |
| 负责人 | 文本 | 必填 |
| 预算（元） | 数值 | 分项估算，与预算表一致 |
| 交付物/证据 | 文本 | 方案、照片、数据表、总结、作品、审批记录 |
| 备注 | 文本 | 依赖条件、风险、去重口径 |

## 生成后必须做的四项一致性校验

1. `年度活动清单` 每行都能在文字版找到对应表述。
2. `量化指标汇总` 的合计值 = `年度活动清单` 对应列求和，且与文字版"年度目标"一致。
3. `专项经费预算` 合计 = `年度活动清单` 预算列求和，且与文字版"资源保障"一致。
4. 时间节点不与监管通知的报送节点冲突；目标人群枚举一致。

任一校验不通过，返回修改后再交付。不得为凑数编造上年度实际值——缺失时填"待补"并在备注列写明数据来源与补齐责任人。
