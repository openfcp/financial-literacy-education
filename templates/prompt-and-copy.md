# 模板：风险提示文案 / 图像生成提示词

> 交付文件名：`文案_{主题}_{日期}.md` 或 `提示词_{用途}_{日期}.md`
> 提示词即交付物；图像生成失败时原样输出提示词并附手动使用建议。

| 项 | 内容 |
|----|------|
| 风险类型 | `[电信诈骗 / 非法集资 / 养老骗局 / 校园贷 / 刷单返利 / 账户出借 / 个人信息泄露 / …]` |
| 目标受众 | |
| 传播渠道 | `[短信 / 公众号 / 折页 / 网点屏 / 广播]` |
| 形式要求 | `[字数、适老版、方言版、音频版]` |
| 法规依据 | `[依据来源：<文件名> · <章节>]` |
| 参考案例 | `[脱敏后的典型案例，来源标注]` |

### 创作输出

**标题**（≤16 字）：
`[用疑问或具体场景，不用公文腔]`

**正文（三段式，缺一不可）**：
1. **风险现象描述**：`[消费者认得出的具体场景，如"有人加您微信说…"]`
2. **后果说明**：`[会损失什么、为什么拿不回来]`
3. **防范建议**：`[一条马上能做的动作]`

**一句话版（短信/微信）**：
`[≤40 字；营销类推送须附拒收/退订方式]`

**适老版**：
`[大字短句、无术语、一句一行动]`

**广播/音频版脚本**（如需）：
`[口语、慢速、重复关键动作]`

## 二、图像生成提示词模板（七段式）

```text
【主体】[画面中心是什么、有谁、在做什么]
【场景】[时间、地点、环境、道具]
【风格】[扁平矢量插画 / 剪纸 / 漫画 / 写实摄影；粗轮廓、无渐变]
【构图】[视角、留白、标题文字区位置]
【配色】[深蓝 #071789 与白色为主；警示色仅用于局部点缀]
【文字】主标题："……"；副标题："……"；风险提示："……"  ← 写明具体文字
【规格】[竖版 3:4 / 横版 16:9 / 方形；分辨率]
【负面词】不得出现具体产品名称、收益数字、购买二维码、机构 logo 推销元素、
          真实人物肖像、可识别个人信息、法条全文、夸张恐吓画面
```

### 合规硬约束

- 不生成产品宣传元素、不虚构机构名称与标志、不把监管标识当装饰。
- 面向老年人的物料写明"字号大、对比度高、文字少"。
- 案例类画面须脱敏。

### 图像生成失败时的降级输出

```text
[提示词全文原样保留]

生成失败说明：[原因]
手动使用建议：
1. 可在其他图像生成工具中粘贴上述提示词重试
2. 调整建议：[2–3 条，如简化主体、拆分文字层后期叠加]
3. 文字建议单独排版，避免模型生成错字
```

- 输出物用途：`[海报 / 折页 / 漫画长图 / H5 首屏]`
- 后续排版要求：`[标题区留白、二维码不得出现]`
- 需人工确认事项：
