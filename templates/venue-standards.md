## 二、线上：消费者权益保护专栏

### 1. 渠道与栏目

| 渠道 | 栏目名称 | 定位 | 发布频率 | 责任人 |
|------|----------|------|----------|--------|
| 官网 | | | | |
| 官方 APP | | | | |
| 微信公众号 | | | | |
| 短视频平台 | | | | |

### 2. 内容规范

- 原创优先；转载须标注来源与授权。
- 面向老年人：大字版长图、方言版音频；面向年轻人：短视频、IP 系列漫画、互动 H5。
- 内容合规自检按 `references/role-content-creation.md` §6 执行。
- 精准风险提示：在重要节点或业务办理关键环节推送；营销类信息提供便捷拒收/退订选择。

### 3. 运营指标

| 指标 | 统计口径 | 采集方式 |
|------|----------|----------|
| 发布数量 | 本期原创/转载分别计数 | 后台 |
| 阅读量 / 播放量 | 注明去重 | 后台 |
| 转发量 / 互动率 | | 后台 |
| 完播率 | 短视频 | 后台 |
| 答题参与人数及得分 | 互动内容 | 后台 |

### 4. 更新与留痕

- 更新频率与责任人（避免"僵尸专栏"）
- 发布截图与后台数据按月归档
- 过期内容下架机制
