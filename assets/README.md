# 金融宣教 · 品牌图标资源

## 设计语言

沿用参考图 `2816.JPG` 的视觉语言：**深蓝底 + 纯白扁平剪影 + 蓝色负空间勾形**，无渐变、无描边、无立体效果。只使用两个主色：

| 用途 | 色值 | 说明 |
|------|------|------|
| 主蓝（背景 / 负空间） | `#071789` | 取自参考图主色像素采样 |
| 纯白（图形 / 文字） | `#FFFFFF` | 参考图的人物与书页剪影色 |
| 辅助蓝（仅横版副标题） | `#4A56A8` | 主蓝降低饱和度，仅用于横版小字，不进入图标 |

## 图形释义

| 元素 | 含义 |
|------|------|
| 白色圆币 + 蓝色 `¥` 负空间 | 金融属性；`¥` 用背景蓝挖出，延续参考图的负空间手法 |
| 圆币下方三道渐短横线 | 知识传播 / 知识之光；与圆币组合亦构成"点亮知识的灯"的双关 |
| 翻开的书 + 页面上两道蓝色文字行 | 教育普及属性；中间 V 形留蓝形成书脊 |
| 整体构图 | 金融知识从书中升起，被传播给公众——对应"公益性、普惠性知识传播者"的岗位定位 |

刻意不复用参考图"读书的人"轮廓，避免形象雷同；仅继承配色、块面剪影与负空间手法。

## 重新生成

```bash
cd assets && python3 render_icon.py
```

字体依赖 macOS 自带 `/System/Library/Fonts/Hiragino Sans GB.ttc`（W6 粗体 / W3 细体）。
SVG 内的文字使用 `PingFang SC / Hiragino Sans GB` 字体栈，在其他系统打开时会回退到系统无衬线中文字体。

## 使用规范

1. 图标最小显示尺寸 48×48 px；小于此时改用 `logo-mark.svg` 纯图形版。
2. 四周留白不小于图标边长的 10%。
3. 不得更换主蓝、不得为图形加渐变/投影/描边、不得拉伸变形。
4. 深色背景场景使用 `icon.svg` / `_icon.png`；浅色背景场景使用 `logo-horizontal.svg`（自带白色底），或直接把深蓝方块图形置于白底。
5. 中文名称固定为「金融宣教」，英文固定为 `Financial Literacy Education`（横版全大写为字距排版需要）。
