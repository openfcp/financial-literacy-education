# R4 效果评估者作业规范

对应职责：对金融教育宣传工作的开展情况与效果做量化评估和质效分析，形成报告，为下一年度工作提供改进依据。

## 1. 指标体系与口径

### 1.1 过程指标

| 指标 | 定义 | 数据来源 | 常见口径问题 |
|------|------|----------|--------------|
| 活动场次数量 | 独立组织的活动次数；同一活动多场次分别计数 | 活动数据统计表 | 把"进社区""进校园"合并计 1 场 |
| 覆盖人次 | 触达的消费者人次 | 线下签到/发放数、线上阅读/播放数 | 线上线下重复计算、未写去重方式 |
| 原创作品数量 | 本期原创图文/视频/H5/音频/漫画成品数 | 作品库 | 转发转载计入原创 |
| 阵地建设覆盖率 | 已建成合规专区（或线上专栏）的网点/渠道数 ÷ 应建总数 | 专区验收记录、专栏上线记录 | 建成但未更新仍计为达标 |
| 参与员工数 | 实际到场参与组织的员工人次 | 活动记录 | 与覆盖人次混用 |
| 费用投入 | 本期宣教专项经费实际支出 | 财务/预算执行表 | 只写预算不写执行 |

### 1.2 结果指标（核心导向）

| 指标 | 说明 | 数据来源 |
|------|------|----------|
| 投诉率变化趋势 | 本期与上期、去年同期的对比 | 投诉台账 |
| 客户满意度调研中的"金融认知指数"提升 | 同一问卷口径下的认知得分变化 | 满意度/认知调研 |
| 销售误导纠纷变化 | 与宣教主题相关的纠纷数量变化 | 投诉分类数据 |
| 风险事件发生率 | 如客户遭遇电信诈骗、非法集资的报案/咨询量 | 风控/客服记录 |

> 结果指标是"核心导向"，但不能凭常识把投诉下降直接归因于宣教。归因分析必须写明其他可能影响因素与证据强度，措辞用"可能相关""有待进一步验证"，不做因果断言。

### 1.3 线上过程数据

阅读量、转发量、完播率、互动率、参与答题人数及得分。完播率与答题得分比阅读量更能反映"有效性"，报告中要单独分析。

## 2. 四步工作流

### 第一步：数据收集

按「活动 / 渠道 / 人群 / 时段」四维整理，形成本期台账。使用 `scripts/campaign_metrics.py` 可从 CSV 明细自动汇总过程指标。

| 维度 | 线下 | 线上 | 业务关联 |
|------|------|------|----------|
| 采集项 | 场次、参与人数、发放资料数、参与员工数 | 阅读、转发、完播、互动、答题得分 | 投诉数据、满意度、风险事件 |
| 校验 | 与活动总结表、签到记录核对 | 与平台后台截图核对 | 与投诉台账口径核对 |

**数据不足时的正确做法**：输出"数据需求清单"（缺什么、谁提供、什么口径、补齐后才能做哪一步），不生成看似完整实则空心的报告，不估算填充缺失值。

### 第二步：数据分析

四类分析都要覆盖，不能只做汇总：

1. **趋势分析**：本期 vs 上期 vs 去年同期，给出变化方向与幅度。
2. **结构分析**：按内容类型、渠道、人群拆解，找出最受欢迎的内容类型与渠道。
3. **缺口分析**：识别覆盖不足的人群、内容同质化程度、线上平台运营薄弱环节。
4. **关联分析**：宣教主题与投诉变化的关联性，结合"投诉中反映的金融知识薄弱点"给出下一期选题建议。

### 第三步：撰写评估报告

固定六段结构：`数据概览 → 成效分析 → 投诉关联分析 → 问题诊断 → 改进建议 → 引用来源`。

- **数据概览**：活动数量、覆盖人次、费用投入与产出比；表格须含本期值、上期值、同比变化、说明四列。
- **成效分析**：按**覆盖度、有效性、影响力**三个维度展开，每个维度有数据、有对比、有解释。
- **投诉关联分析**：说明使用的是哪一类投诉数据、口径是否可比、关联性与局限。
- **问题诊断**：表格列"问题描述 / 严重程度 / 影响范围 / 证据"，严重程度分高/中/低并说明分级依据。
- **改进建议**：表格列"改进方向 / 具体措施 / 责任方 / 建议时限"，措施要可执行、可验收。
- **引用来源**：逐项列出知识库文件名、数据来源、统计周期。

### 第四步：经验沉淀

把好的活动创意、优秀宣传作品、成功合作案例提炼为《优秀宣教案例集》，格式见 `templates/case-collection.md`。每条案例写清：背景、目标人群、做法、可复用要点、效果证据、适用条件与不适用情形。

## 3. 两条硬约束

1. **有数据有对比**：不可只罗列数据，必须包含趋势对比与归因分析。缺少上期数据时，明确标注"同比数据缺失"，并列出需补数据项，不得留空或编数。
2. **数据可追溯**：每个数字标注来源（台账文件、平台后台、用户提供文件）；估算值必须标明"估算"并给出估算口径。

## 4. 从评估到闭环

评估报告不是终点。在"改进建议"里明确三类回流：

| 回流到 | 触发条件 | 链式角色 |
|--------|----------|----------|
| 体制机制管理者 | 制度或年度计划存在结构性缺口 | R4 → R1（评估-机制链） |
| 活动组织策划者 | 渠道覆盖不足、活动形式效果差 | 反馈结果作为下期策划输入 |
| 内容创作者 | 内容同质化、某类内容完播率低 | 反馈结果作为下期选题输入 |

## 5. 常见不合格表现

- 只有本期数据罗列，没有上期/同期对比。
- "成效显著""效果良好"等结论没有数据支撑。
- 把投诉量下降直接写成"宣教成效"，不考虑其他因素。
- 覆盖人次把线上阅读量与线下到场人数直接相加且不注明去重。
- 问题诊断写成"宣传力度还需加强"，无证据、无影响范围。
- 改进建议无责任方、无时限，无法验收。
- 引用来源只写"内部数据"，无法追溯。
