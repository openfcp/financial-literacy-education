# R2 活动组织策划者作业规范

对应职责：按监管统一部署组织集中式大型宣教活动，建设线上线下宣教阵地，策划并执行日常金融知识普及与风险提示活动。

## 1. 第一步：解读监管方案（最高频差错点）

拿到监管通知后，先建一张**逐字核对表**，不要凭印象写方案：

| 核对项 | 要落到方案里的字段 | 常见差错 |
|--------|-------------------|----------|
| 活动主题 | 主题全称、口号、统一标识使用要求 | 沿用去年主题、自行改写主题词 |
| 活动时间 | 启动/结束日期、阶段性节点 | 把宣传周写成宣传月 |
| 重点内容 | 监管列明的重点宣教内容清单 | 只写本机构想讲的产品知识 |
| 报送对象 | 具体接收单位/部门/系统 | **报错单位**，是最严重的低级错误 |
| 报送内容 | 报告模板、数据表、照片、作品清单 | 少交附件 |
| 报送时间 | 截止日期与时点 | 压线报送、错过节点 |
| 数据统计口径 | 场次、参与员工数、覆盖人次的定义 | 各分支机构口径不一致导致汇总失真 |

**核对结果的写法**：把上述字段作为方案"活动概况"的强制字段逐条列出，并在方案末尾附 `[依据来源：<通知文件名>]`。

## 2. 第二步：制定本级实施方案（八部分）

1. **活动概况**：主题（逐字）、时间、目标受众、形式（线上/线下/结合）、预计覆盖人次。
2. **组织架构**：活动领导小组、牵头部门、配合部门、分支机构的责任分工。
3. **活动安排表**：见 §3 五要素。
4. **物料清单**：见 §6。
5. **阵地与渠道安排**：线下专区、厅堂微沙龙、线上专栏、精准推送。
6. **舆情应对预案**：见 §7。
7. **数据报送要求**：报送时间、内容、对象、口径、责任人。
8. **引用来源与附件**：知识库文件名及具体章节。

方案必须**先经知识库检索**再写，主题与报送要求以监管原文为准，不用常识补齐。

## 3. 活动安排表（五要素，缺一不可）

| 序号 | 活动内容 | 形式 | 时间 | 地点/渠道 | 负责人 | 预计覆盖人次 |
|------|----------|------|------|-----------|--------|-------------|

五要素：**主题、时间、地点/渠道、负责人、预计覆盖人次**。主题在"活动概况"中给出；表内每一行都要能对应到主题下的具体任务。表中不得出现"待定"以外的空值——确属待定的，在备注列写明确定时限与责任人。

## 4. 集中式活动六步执行

| 步 | 动作 | 关键控制 |
|----|------|----------|
| 1 | 解读监管方案 | 逐字核对表（§1） |
| 2 | 制定本级方案 | 结合本机构特色，八部分齐全 |
| 3 | 物料统一与分发 | 统一设计主题海报、折页、易拉宝；全行视觉形象统一；**提前**配发到各网点，附配发清单与签收 |
| 4 | 组织现场活动 | "进农村、进社区、进校园、进企业、进商圈"五进入；联合或指导分支机构执行 |
| 5 | 挖掘亮点与创新 | 联合反诈中心做"情景模拟+案例警示"、老年大学合作、原创短视频、金融知识快闪、有奖问答等 |
| 6 | 数据统计与材料报送 | 汇总活动次数、参与员工数、覆盖人次、媒体报道情况；撰写总结报告；按节点报送 |

### 五进入的受众适配

| 场景 | 内容重心 | 形式建议 |
|------|----------|----------|
| 进农村 | 防范非法集资、识别假币、安全用卡、征信基础 | 方言广播、赶集日摆摊、大喇叭、图文展板 |
| 进社区 | 电信诈骗、养老骗局、理财风险 | 社区讲座、情景短剧、案例展板、咨询台 |
| 进校园 | 校园贷、征信、理性消费、个人信息保护 | 互动游戏、知识问答、漫画长图 |
| 进企业 | 员工防诈、工资卡安全、企业账户风险 | 午间微讲堂、内刊专栏 |
| 进商圈 | 支付安全、刷单返利、虚假投资平台 | 快闪、互动 H5、扫码答题 |

## 5. 阵地建设

### 5.1 线下专区

| 要素 | 标准 |
|------|------|
| 位置与标识 | 营业场所内**独立**区域，标识清晰统一为"公众教育区 / 金融知识教育专区" |
| 资料 | 折页、手册、风险提示牌充足；按人群配备大字版、方言版 |
| 设备 | 多媒体设备滚动播放消保宣传片，可正常播放 |
| 更新 | 明确规定资料更新频率与责任人，确保内容时效性 |
| 留痕 | 专区照片、资料清单、更新记录、设备巡检记录 |

### 5.2 厅堂微沙龙

- 利用客户等候时间，单场 **10–15 分钟**，形式轻松。
- 内容贴合热点：防范电信诈骗、安全用卡、征信知识等。
- 一次只讲一个知识点，配一个生活比喻、一个真实案例、一条可带走的行动建议。
- 产出简报：时间、网点、主题、参与人数、客户提问、发放资料数、现场照片。

### 5.3 线上阵地

- 官网 / 官方 APP / 微信公众号建"消费者权益保护"专栏，定期发布原创图文、短视频、以案说险。
- 年轻人 → 短视频平台（抖音、视频号）内容创新，打造特色 IP。
- 老年人 → 大字版、方言版长图或广播音频。
- **精准推送**：在重要节点或业务办理关键环节做风险提示；营销类信息须提供便捷拒收/退订选择。
- 避免"全面开花却都不深入"：按目标客群选 1–2 个核心渠道做深做透，并在方案中写明选择理由。

### 5.4 外部合作

与社区、学校、企业、老年大学、媒体等建立合作，共建阵地（如高校"金融素养实践基地"）。合作协议/备忘录需明确双方职责、内容合规边界、素材使用授权、数据归属。

## 6. 物料清单

| 物料名称 | 数量 | 用途 | 制作要求 | 配发对象 | 到位时间 |
|----------|------|------|----------|----------|----------|

制作要求必须写清：统一主题标识、视觉规范、公益属性（无产品营销元素）、适老版本（字号、对比度）、无障碍要求、印刷/投放规格。视觉形象统一是监管检查中容易被扣分的点。

## 7. 舆情应对预案

| 项 | 内容 |
|----|------|
| 可能风险点 | 现场秩序、客户误解为产品推销、宣传表述被质疑、合作方不当表述、线上内容被误读、个人信息收集争议 |
| 预防措施 | 物料事前合规复核、现场话术统一、不采集无关个人信息、明确"公益宣教非营销"的现场说明 |
| 监测与响应 | 责任部门、监测渠道、响应时限、分级处置、统一对外口径 |
| 升级路径 | 分支机构 → 牵头部门 → 消保/品牌/法务 → 领导小组 |
| 留痕 | 处置记录、沟通记录、整改记录 |

## 8. 数据报送与活动总结

**过程数据口径**（各分支机构必须统一，方案里就写清定义）：

- 活动次数：一次独立组织的活动计 1 次，同一活动多场次分别计数。
- 参与员工数：实际到场参与组织的员工人次。
- 覆盖人次：触达的消费者人次（线上按阅读/播放口径，注明去重方式）。
- 发放资料数量、媒体报道情况（媒体名称、链接/截图、发布时间）。

总结报告结构：`活动概况 → 组织与实施 → 数据成果（含表）→ 亮点与创新 → 问题与不足 → 下一步计划 → 附件（照片、新闻稿、媒体报道、物料样张）`。

报送前逐项对照 §1 的核对表，确认报送对象、内容、时间无误。

## 9. 常见差错速查

- 主题沿用去年、报送对象搞错、错过报送节点。
- 方案只有活动安排表，缺组织架构、物料清单、舆情预案、报送要求。
- 活动安排表缺"负责人"或"预计覆盖人次"。
- 宣教物料出现产品名称、收益率、二维码购买入口（违反公益性定位）。
- 线上线下数据口径不一致，覆盖人次重复计算。
- 活动做完没留照片、签到、发布截图，考评时拿不出证据。
- 专区建成后不更新资料，内容过期。
