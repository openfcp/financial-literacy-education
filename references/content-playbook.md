# 内容创作素材库：比喻、受众、渠道、形式

面向消费者的宣教内容，成败在"翻译"而非"准确复述法条"。本文件提供可直接取用的比喻、受众画像与载体选择依据。创作时先查本文件，再动笔。

## 1. 生活比喻库

| 知识点 | 大白话比喻 | 可直接用的 sentence |
|--------|-----------|--------------------|
| 保险互助原理 | 面馆续面 | 大家各出一碗面钱，谁哪天没带饭，就能用这锅面续一碗——保险就是"一人有难，大家凑份子"。 |
| 免赔额 | 开车保险杠 | 小剐蹭自己修，撞狠了保险才上场；免赔额就是"这一点点小钱自己扛"。 |
| 复利 | 滚雪球 | 雪球越滚越大，是因为新沾上的雪也会继续沾雪；利息再生利息就是这个道理。 |
| 分散配置 | 鸡蛋别放一个篮子 | 篮子翻了不至于全碎，但也不是篮子越多越好——太多你看不过来。 |
| 流动性 | 随身零钱 vs 保险柜 | 活期是口袋里的零钱，随时能用；长期产品像锁进保险柜，提前开要费事还可能折损。 |
| 征信 | 经济身份证 | 借了钱按时还，等于在这张身份证上记一笔好评；逾期就是记一笔赖账，下次办事别人会先翻它。 |
| 风险测评 / 适当性 | 买鞋先量脚 | 鞋不合脚磨的是自己的脚；产品不匹配风险承受能力，亏的是自己的钱。 |
| 适当性（进阶） | 处方药不能随便买 | 别人吃着管用，不代表你的体质能吃。 |
| 电信诈骗核验 | 挂断再回拨 | 陌生来电先挂，自己翻出官方号码打回去——真有事，回拨一定找得到人。 |
| 非法集资"保本高息" | 天上掉馅饼 | 又保本又给高息，等于有人白送钱还倒贴；先问一句：他靠什么赚回这笔钱？ |
| 个人信息保护 | 家门钥匙 | 身份证复印件、验证码像家门钥匙，别随手拍给陌生人。 |
| 授权范围 | 配几把钥匙、能开哪扇门 | 授权书要看清"给谁、能用多久、能开哪扇门"，别签"全都能用"。 |
| 保单犹豫期 | 网购七天无理由 | 签完还有一段反悔期，看清楚条款，不合适可以退。 |
| 免责条款 | 雨伞不保故意戳破 | 伞能挡雨，但自己把伞戳个洞再怪伞漏，就不在保障范围内。 |
| 净值波动 | 坐船有起伏 | 水面起伏是常态，不等于船要沉；看的是航线，不是每一道浪。 |
| 提前支取 | 没到站下车 | 车没到站要下车，票钱通常退不全。 |
| 反洗钱 / 账户出借 | 门牌不能借人挂 | 自家账户像自家门牌，借给别人挂，出了事先找门牌主人。 |
| 杀猪盘 | 先喂食再收网 | 先让你尝点甜头、夸你聊得来，等信任攒够了才开口要钱。 |
| 刷单返利 | 鱼饵 | 头两单真给佣金，是鱼饵；等加大投入，鱼竿就收了。 |
| 电信诈骗共性 | 三不一多 | 陌生链接不点、陌生来电不轻信、验证码不给、遇到拿不准的多问家人或去网点核实。 |

**使用规则**：一个知识点只用一个比喻，讲透为止；比喻必须贴近目标人群的日常生活（对县域居民少用"净值""复利"这类词作比，多用赶集、存粮、借还）。

## 2. 受众分层与触达

| 人群 | 信息接收偏好 | 首选渠道 | 内容形式 | 必须注意 |
|------|--------------|----------|----------|----------|
| 老年人 | 慢、反复、信任熟人/网点 | 社区讲座、营业网点、广播、大字版长图 | 大字、短句、方言、音频、真人讲解、情景剧 | 字号与对比度、不放二维码购买入口、给"能带走的一张纸" |
| 年轻人 | 快、碎片、社交分享 | 抖音/视频号、公众号、H5、互动问答 | 60–120 秒短视频、IP 系列漫画、测试类 H5 | 不硬广、不端着说教、结尾给可执行动作 |
| 县域农村居民 | 熟人社会、集市、广播 | 赶集日摆摊、村广播、村委会 | 方言音频、展板、案例故事 | 少术语、多"身边事"、避免纯线上 |
| 新市民 / 务工人员 | 移动端、夜间、实用导向 | 短信、微信群、企业午间讲堂 | 一句话风险提示、工资卡安全、租房押金陷阱 | 推送需可拒收/退订 |
| 在校学生 | 互动、社交、竞赛 | 校园活动、社团、短视频 | 知识问答、漫画、实景游戏 | 校园贷、征信、个人信息保护；不诱导开户 |
| 企业经营者 | 效率、合规、案例 | 企业讲堂、协会、内刊 | 账户风险、员工防诈、政策解读 | 不夹带产品推介 |

## 3. 形式矩阵

| 形式 | 具体载体 | 适用场景 | 制作要点 |
|------|----------|----------|----------|
| 视频 / 音频 | 宣传片、人物访谈、防诈微电影、AI 互动视频、广播音频 | 线上传播、社交媒体、老年群体 | 先故事后分镜；静音也能看懂（字幕）；单条只讲一个知识点 |
| 图文 | 漫画长图、IP 系列漫画、大字版长图、折页 | 公众号、网点专区、社区 | 一图一主题；适老版字号与对比度 |
| 游戏 / 互动 | 有奖知识问答、消保实景游戏、互动 H5 | 线下活动、线上互动 | 题目基于真实风险场景；不收集无关个人信息 |
| 特色活动 | 体育赛事联动、金融知识快闪、消保歌曲 | 线下大型活动 | 提前做舆情预案与现场秩序方案 |
| 业务流程内 | 双录话术、条款大白话图示、销售"必须说清楚"清单 | 销售现场 | 如实告知风险、清晰解释条款；可留痕 |

## 4. 渠道选择规则

1. 按目标客群选 1–2 个核心渠道做深做透，避免"全面开花却都不深入"。
2. 在方案中写明**为什么选它**（覆盖人群、触达成本、可留存的数据）。
3. 线上线下数据口径分开统计，覆盖人次注明去重方式。
4. 专栏类渠道必须写明发布频率与更新责任人，否则容易建成"僵尸专栏"。
5. 营销类精准推送必须提供便捷拒收/退订选择。

## 5. 标题与开头

- 标题不超过 16 字，用疑问或具体场景，不用"关于进一步加强……的通知"式公文腔。
- 开头 3 秒（或前 1 行）必须出现消费者认得出的场景，而不是定义。
- 结尾固定给一条能马上做的动作。
- 好标题示例：「高息保本？先别急着点」「验证码，是家门钥匙」「这张纸，别随手拍给别人」「陌生来电先挂断，再回拨」。

## 6. 禁用表达清单

| 类别 | 禁用 |
|------|------|
| 收益承诺 | 保本、稳赚、零风险、最高收益、保证收益、稳赢 |
| 营销诱导 | 产品名称、收益率、购买入口、二维码、限时办理、优惠话术、机构 logo 推销元素 |
| 法律定性 | "机构全责""必须赔付""构成诈骗（判定式）"；以案说险只讲现象与防范 |
| 空话 | "提高风险意识""增强防范能力"（作为唯一建议时出现即为不合格） |
| 未核实 | 具体文号、条款号、处罚金额、统计数字，未经知识库或官方原文核验一律标 `[待验证]` |
| 个人信息 | 真实姓名、账号、身份证号、可识别照片（案例必须脱敏） |

## 7. 避免内容同质化

- 动笔前检索 `doc_class=内容作品` 的历史作品，若同一主题已有 3 个以上同类作品，换角度（换人群、换场景、换形式），不换汤不换药地重写一遍。
- 用 `web_search` 找行业创新案例与新型诈骗手法时，标注外部来源并提示人工复核。
- 从投诉关联分析中找选题：投诉里反复出现的知识薄弱点，优先做内容。
