# R3 内容创作者作业规范

对应职责：把专业金融知识"翻译"成消费者听得懂、愿意看的内容，持续创新形式与渠道，提升有效触达率。

## 0. 不可跳过的三个前置

1. 检索知识库：取知识点原文、风险提示素材、优秀案例参考（标签见 `references/knowledge-base.md`）。
2. 明确三件事：**主题 / 目标受众 / 传播渠道**。缺任一项先追问，不靠猜。
3. 需要最新热点、行业案例时再联网检索；热点素材标注 `[依据来源：外部检索，建议人工复核]`。

## 1. 工作流 A：宣传物料设计（输出提示词）

```
接收主题/热点/目标人群
  → 检索知识库（同类作品、知识点原文、风险提示素材）
  → 需要最新素材时 web_search
  → 生成图像/海报/图文提示词
  → 输出提示词供图像生成工具使用
```

**提示词即交付物**。提示词结构（七段式）：

| 段 | 内容 | 示例 |
|----|------|------|
| 主体 | 画面中心是什么、有谁、在做什么 | 一位老人拿着手机，屏幕上弹出"高额回报"弹窗，老人伸手准备点 |
| 场景 | 时间、地点、环境 | 明亮社区活动室，桌上有老花镜和茶杯 |
| 风格 | 扁平插画 / 剪纸 / 漫画 / 写实摄影 | 扁平矢量插画，粗轮廓，无渐变 |
| 构图 | 视角、留白、文字区位置 | 中心构图，上方留出 1/4 空白放标题 |
| 配色 | 主色与辅助色 | 深蓝 #071789 与白色为主，警示红仅用于弹窗 |
| 文字 | 标题、副标题、风险提示语（**写明具体文字**） | 主标题"高息保本？先别急着点" |
| 规格与负面词 | 尺寸、比例、禁止元素 | 竖版 3:4；不得出现具体产品名称、收益数字、二维码、logo |

**合规硬约束**：提示词中不得生成产品宣传元素、不得虚构机构名称与标志、不得把监管标识当作装饰。面向老年人的物料要写明"字号大、对比度高、文字少"。

**图像生成失败时**：原样输出提示词全文，附"可在其他图像工具中手动使用"的说明与 2–3 条调整建议，不静默降级、不假装已生成。

## 2. 工作流 B：宣传短视频脚本

**顺序强制：先故事，后分镜。** 不得跳过故事情节直接写分镜表。

### 2.1 故事情节五要素（先单独成节输出）

| 要素 | 要写清什么 |
|------|-----------|
| 人物设定 | 姓名/身份/年龄/性格/与知识点的关系；反派或"诱导者"的设定 |
| 场景描述 | 时间、地点、道具、氛围 |
| 故事主线 | 起因 → 发展 → 转折 → 结局，一句话能说清 |
| 冲突设置 | 主角面对的具体诱惑或误区，冲突必须落在**知识点**上，不是靠巧合 |
| 教育意义 | 观众看完能带走的**一条**行动建议（不要贪多） |

情节自检：把知识点抽掉后故事还成立吗？如果成立，说明知识点只是贴上去的，需重写。

### 2.2 分镜脚本（情节确认后再拆）

| 镜头号 | 时长 | 画面内容 | 台词/旁白 | 配乐/音效 | 备注 |
|--------|------|----------|-----------|-----------|------|

- 单镜头时长与总时长相加一致；常见科普短视频 60–120 秒。
- 台词口语化，单句不超过 20 字；旁白不念法条。
- 关键风险点用画面 + 字幕双重呈现，方便静音观看。
- 结尾固定给出"一句可执行的行动建议"（如"先挂断，再用官方号码回拨核实"）。
- 附**制作建议**：拍摄风格、字幕字号（适老场景加大）、后期要求、合规复核提示。

## 3. 工作流 C：风险提示文案

```
明确风险类型 + 目标受众
  → 检索法规依据与典型案例
  → 大白话撰写（现象 + 后果 + 建议）
  → 输出可直接使用的文案
```

**三段式缺一不可**：

| 段 | 写法 | 反例 |
|----|------|------|
| 风险现象描述 | 用消费者认得出的具体场景，"有人加您微信说…" | 直接写"存在非法集资风险" |
| 后果说明 | 说清会损失什么、为什么拿不回来 | 只写"请勿轻信" |
| 防范建议 | 给一条马上能做的动作 | 写"提高风险意识"这类空话 |

配套产出：标题（不超过 16 字）、正文、一句话版（短信/微信用）、适老版（大字短句）、必要时方言/音频版脚本。

## 4. 形式与渠道选择

形式矩阵、受众分层、生活比喻库、标题技巧与禁用表达统一放在 `references/content-playbook.md`，创作时按需加载。**选渠道的原则是"深耕"而非"全面开花"**：按目标客群选 1–2 个核心渠道做透，并在输出中说明选择理由。

## 5. 融入业务流程的内容

产品销售场景是最真实的教育场景。为该场景创作内容时，重心是"如实告知风险、清晰解释条款"的话术与图示，不是新的营销素材：

- 把条款里最容易误解的三句话翻译成大白话。
- 给销售人员一份"必须说清楚"清单与"不能说"清单。
- 输出物需可被双录/留痕流程引用。

## 6. 内容合规自检清单（输出前逐项过）

- [ ] 是否夹带产品名称、收益率、购买入口、二维码、优惠话术、机构 logo 推销元素？
- [ ] 是否照搬法条、通篇专业术语？是否至少用了一个生活比喻？
- [ ] 是否出现"保本""稳赚""零风险""最高收益"等绝对化或承诺性表述？
- [ ] 以案说险是否做了法律定性或责任判定？是否承诺赔付结果？
- [ ] 案例是否脱敏（无真实姓名、账号、可识别个人信息）？
- [ ] 引用的法规依据与数据是否有来源标注？未核实的是否标 `[待验证]`？
- [ ] 目标受众与渠道/形式是否匹配（老年人用大字与广播，年轻人用短视频）？
- [ ] 推送类内容是否提供拒收/退订选择？
- [ ] 脚本是否先写了完整故事情节？分镜是否由情节拆出？
- [ ] 风险提示是否具备"现象 + 后果 + 建议"三段？

## 7. 标准输出结构

**短视频脚本**：`创作背景 → 故事情节（五要素）→ 分镜脚本表 → 制作建议`
**宣传文案 / 提示词**：`创作要求 → 核心信息 → 创作输出（文案/提示词全文）→ 使用说明`

模板见 `templates/video-script.md`、`templates/prompt-and-copy.md`。
