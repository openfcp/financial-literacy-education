# R1 体制机制管理者作业规范

对应职责：建立常态化金融教育宣传机制，制定年度工作计划并纳入消费者权益保护全流程工作体系。

## 1. 四条刚性要求的落地检查表

生成任何 R1 交付物后，逐条自检；任一条不满足即返工。

| # | 刚性要求 | 检查点 | 不合格的典型表现 |
|---|----------|--------|------------------|
| 1 | **年度计划双格式** | 是否同时输出文字版与表格版？表格版是否逐项列明场次/人次/预算/时间/责任部门？ | 只给一份 Word；表格只有活动名称没有量化指标 |
| 2 | **制度覆盖五环节** | 办法是否明确"计划制定→活动策划→组织实施→材料报送→总结评估"，且每一环节写清牵头与配合部门？ | 流程只写到"组织实施"，漏报送与评估 |
| 3 | **融入业务全流程并留痕** | 是否在产品服务营销方案、业务培训计划中嵌入教育环节？是否提示留痕存档？ | 宣教被写成"业务之外的额外任务" |
| 4 | **经费保障可核查** | 是否在年度预算中单列专项宣教经费？是否覆盖物料、媒体投放、场地？ | 预算表只有总数无分项，或完全没提经费 |

> 第 4 条是消保监管评价中"规划与投入"的直接证据，不可省略。

## 2. 分支 A：年度计划

### 2.1 依据组合

监管年度部署要求 + 机构业务重点 + 历年计划与评估报告 + 消保监管评价中与教育宣传相关的评分维度和证据要求。**先看评价标准再定指标**，否则计划里的指标对不上考评口径。

### 2.2 文字版结构

1. **年度目标**：定性 + 可核查的定量目标（活动场次、覆盖人次、重点人群覆盖率、原创作品数）。
2. **整体思路**：常态化机制 + 集中式活动 + 阵地建设 + 内容创新 + 评估闭环，说明五者关系。
3. **重点人群**：老年人、年轻人、县域农村居民、新市民、在校学生、企业经营者等，逐类说明为什么是重点、打算怎么触达。
4. **核心主题**：结合监管年度主题与机构投诉数据反映的知识薄弱点确定，说明选题依据。
5. **资源保障**：组织分工、专项经费、物料与渠道、外部合作。
6. **评估与改进**：数据口径、季度/年度评估安排、结果如何反馈到下一年计划。

### 2.3 表格版字段（Excel）

| 列名 | 说明 |
|------|------|
| 序号 | — |
| 活动/任务名称 | 与文字版章节对应 |
| 类型 | 集中式活动 / 日常普及 / 阵地建设 / 内容创作 / 内部培训 / 评估改进 |
| 目标人群 | 与文字版重点人群一致 |
| 渠道/形式 | 网点、社区、校园、公众号、短视频、广播等 |
| 量化指标 | 活动场次、预计覆盖人次、原创作品数 |
| 时间节点 | 起止月份或具体日期，必须与监管时间节点对齐 |
| 责任部门 | 牵头部门 + 配合部门 |
| 预算（元） | 分项估算 |
| 交付物/证据 | 方案、照片、数据表、总结、作品 |
| 备注 | 依赖条件、风险 |

**双格式一致性校验**：表格版的活动清单必须能在文字版中找到对应表述；量化指标合计必须与文字版年度目标一致；预算合计必须与分支 C 的预算表一致。

## 3. 分支 B：管理办法

### 3.1 六章骨架

| 章 | 必备内容 |
|----|----------|
| 总则 | 目的与依据、适用范围、 definitions（金融教育宣传、公益性定位）、基本原则（公益性、普惠性、常态化、不得夹带营销） |
| 组织架构 | 牵头部门、配合部门、领导小组、分支机构职责 |
| 职责分工 | 逐部门列明在五环节中的具体职责，避免"相关部门配合"这类无法核查的表述 |
| 工作流程 | **计划制定 → 活动策划 → 组织实施 → 材料报送 → 总结评估** 五环节逐节展开，每节写输入、责任主体、输出、时限 |
| 考核评价 | 过程指标与结果指标、数据来源、评估周期、结果运用（与下一年度计划/预算挂钩） |
| 附则 | 解释权、生效日期、修订程序、附件清单 |

### 3.2 修订场景

修订时额外输出**变更说明**：变更条款对照表（原表述 / 新表述 / 变更依据 / 影响范围），并标注依据来自哪份监管文件或内部制度。不得静默改写已生效条款。

## 4. 分支 C：预算规划

从年度计划活动清单逐项估算，不许只给总数。常用科目：

| 科目 | 明细 |
|------|------|
| 物料制作 | 海报、折页、手册、易拉宝、专区标识、大字版/方言版资料 |
| 内容制作 | 短视频拍摄、漫画/H5 设计、音频录制、IP 形象设计 |
| 媒体投放 | 公众号推广、广播时段、社区媒体、短视频平台投放 |
| 活动场地与执行 | 场地、设备、交通、讲师、合作单位费用 |
| 阵地建设 | 专区家具、多媒体设备、资料更新 |
| 评估与调研 | 满意度调研、问卷、数据分析工具 |
| 预备费 | 舆情应对、临时增补活动 |

输出预算表后附"编制口径说明"：估算依据、单价来源、与历年决算的差异原因。

## 5. 分支 D：专业答疑

1. 匹配问题对应的监管原文与内部制度条款。
2. 答复结构：**结论（一句话）→ 依据原文摘录 → 适用说明 → 落地建议 → 需人工确认事项**。
3. 引用精确到文件名与章节；文号、条款号未经知识库核验标 `[待验证]`。
4. 问题超出教育宣传范畴时，返回主 Agent 并建议对应子 Agent，不硬答。

## 6. 融入业务全流程的检查清单

在审阅或起草产品服务营销方案、业务培训计划时，逐项确认：

- [ ] 是否在客户决策的关键节点设置了风险告知或知识说明，而不是只在附录里放一段免责声明？
- [ ] 销售人员话术是否如实告知风险、清晰解释条款？
- [ ] 是否把"讲清楚"本身计为一次消费者教育，而非额外任务？
- [ ] 相关文件是否可留痕存档（版本、日期、责任部门、审批记录）？
- [ ] 是否避免出现产品名称、收益率、购买入口、优惠话术等营销元素？
- [ ] 精准推送类信息是否提供拒收/退订选择？

## 7. 二次合规复核清单

输出前把下列内容反向检索知识库交叉核对：

- [ ] 监管年度主题、时间节点、报送对象是否与通知原文逐字一致？
- [ ] 引用的制度/法规是否 `effective_status=现行`？
- [ ] 指标口径是否与消保监管评价的证据要求一致？
- [ ] 量化指标、预算数字是否都能追溯到来源（用户提供数据 / 台账 / 估算口径）？
- [ ] 是否存在与存量制度冲突的表述？
- [ ] 输出中是否有未标注来源的断言？

```markdown
- 参考素材：[引用的内部文档 + 出处标注]

```
